# cursi_presentation

Site personnel de **Zzz_cursi (ᴄᴜʀsɪ)** — 19 ans, étudiant en informatique à
Brazzaville, joueur Free Fire **Élite Héroïque** du clan **ɴᴏᴛ ʟɪᴋ s**,
sur le jeu depuis **2019**.

## Sections (une page qui défile)

- **Accueil** — nom, devise, personnage Free Fire
- **Moi** — fiche d'infos complète (pseudo, âge, ville, études, clan, rang,
  UID copiable), compteurs animés (2 500+ h, 5 000+ Booyahs)
- **Mon monde** — deux cartes : l'informatique (C++ excellent, bases de données
  moyen, vibe coding à fond) et Free Fire (compétences + projets en cours)
- **Parcours** — chronologie 2019 → aujourd'hui
- **Galerie** — images avec visionneuse + emplacement pour capture de statistiques
- **Contact** — formulaire fonctionnel + liens directs (e-mail, Discord, WhatsApp, Instagram)

## Fonctionnalités

- 100 % statique, sans dépendance — HTML/CSS/JS vanilla
- Ton sérieux & élégant : thème sombre, accents dorés, Cormorant Garamond + Jost
- Responsive (menu burger mobile), animations au scroll, lien de menu actif
- Compteurs animés au format lisible, copie presse-papiers avec toast
- Visionneuse d'images (clic, Échap, clic extérieur)
- Formulaire de contact avec validation et ouverture de la messagerie
- Bouton retour haut de page

## Lancer en local

```bash
python3 -m http.server 8080
# puis ouvrir http://localhost:8080
```
